SKILLY - GUIA DE BASE DE DATOS (XAMPP + MySQL)
==============================================

INSTALACION (primera vez)
1. Instala Node.js (https://nodejs.org) y XAMPP (https://www.apachefriends.org).
2. Abre el "XAMPP Control Panel" y pulsa START en MySQL (y en Apache para usar phpMyAdmin).
   MySQL debe quedar en verde, puerto 3306.
3. Abre http://localhost/phpmyadmin -> pestana "Importar" -> "Elegir archivo" ->
   selecciona  Skilly-Web/database/skilly.sql  -> "Importar".
   OJO: este script BORRA y recrea la base "skilly" (si tenias datos, haz una exportacion antes).
4. Abre CMD dentro de la carpeta Skilly-Web y ejecuta:  npm install
5. Inicia el proyecto:  node server.js   (o doble clic en INICIAR.bat)
   Abre http://localhost:3000   (admin: admin@skilly.cl / admin123)
   Los datos se ven en phpMyAdmin > skilly.

Usuario XAMPP por defecto: root, sin clave. Si lo cambiaste:
   set DB_USER=root
   set DB_PASS=tuclave
   set DB_HOST=localhost
   set DB_PORT=3306
   set DB_NAME=skilly
   node server.js

TABLAS QUE USA EL PROYECTO
usuarios .............. Todos los usuarios (admin, cliente, empresa, profesional). Clave cifrada.
clientes .............. Perfil de persona sin empresa.
empresas .............. Perfil de empresa (razon social, RUT, contacto, industria).
profesionales ......... Perfil de talento (especialidad, tarifa_hora, LinkedIn, estado, entrevistas, alertas).
bloques_disponibilidad  Bloques de disponibilidad del profesional (max. 4 horas).
reservas .............. Reservas: bloque, profesional, cliente/empresa o invitado, montos, estado.
pagos_escrow .......... Dinero en custodia por reserva (retenido / liberado / reembolsado). Lo genera el servidor.
boletas ............... Boleta del profesional al completarse el servicio.
reclamos .............. Historial de reclamos (reputacion interna que ve Skilly).
feedback_clientes ..... Feedback privado de clientes hacia Skilly.
sesiones .............. Sesiones iniciadas.
configuracion ......... Comision %, penalizacion % y horas maximas (una fila).

TABLAS CONSERVADAS (aun sin uso en el proyecto)
categorias, servicios_marketplace, mensajes, auditorias_talento, documentos_onboarding.
El servidor no las modifica; quedan listas para futuras funciones.

COMO FUNCIONA LA CONEXION
- database.js carga las tablas al iniciar y las guarda en MySQL cada vez que algo cambia.
- server.js y las paginas no cambian: database.js traduce entre sus datos y las tablas de arriba.
- Los IDs de usuario/reserva son texto (ej. "a1b2c3d4e5"), generados por el servidor.
- id_cliente / id_empresa / id_profesional son iguales al id_usuario de esa persona.

PROBLEMAS FRECUENTES
- "ECONNREFUSED": MySQL esta apagado en XAMPP. Pulsa START.
- "Unknown database 'skilly'": falta importar database/skilly.sql.
- "Table 'skilly.usuarios' doesn't exist": importaste otro skilly.sql; importa el de la carpeta database/.
- "Access denied": usuario/clave distintos; usa DB_USER y DB_PASS.
- "Cannot find module 'mysql2'": ejecuta npm install en la carpeta del proyecto.
- Puerto 3306 ocupado: cambialo en XAMPP o define DB_PORT.
- No edites a mano las tablas con el servidor encendido: el servidor guarda su copia en memoria y la sobrescribe.
